# RamClean — What's Where

```
RamClean/
├── README.md                     At-a-glance page: screenshots, diagram, links
├── RamClean.md                   The project brief, open questions and changelog
├── project.yml                   xcodegen spec for the Mac app, Sparkle package and its public key (RamClean.xcodeproj is generated, not committed)
├── scripts/
│   ├── build.sh                  Generate the project, build Release, copy to build/RamClean.app
│   ├── release.sh                Developer ID sign, notarize, staple and make the DMG you sell (--check: only check the setup)
│   ├── make-icon.swift           Draws the app icon and writes App/Assets.xcassets (swift scripts/make-icon.swift)
│   └── make-notification-art.swift Draws the pictures in App/NotificationArt
├── App/                          The Mac app (SwiftUI + AppKit)
│   ├── RamCleanApp.swift         App entry: main window, menu bar item, Settings scene, app delegate
│   ├── AppModel.swift            Runs the checks, habit tracking, quitting, answers, retraining; Format helpers
│   ├── Notifier.swift            Notifications with Quit / Keep / Always keep / Force Quit buttons
│   ├── MainView.swift            Sidebar window, Overview page, app rows, stable row order
│   ├── HabitsAndModelViews.swift Habits table, Activity Log, Model page
│   ├── MenuBarView.swift         Menu bar popover
│   ├── SettingsAndFeedback.swift Settings tabs (General, Thresholds, Protection, Data, Licence) and the Feedback sheet
│   ├── Updater.swift             Sparkle auto-updates (Check for Updates…)
│   ├── RecommendationViews.swift Popovers behind the Memory, CPU and Disk bars (what to quit, what to clear)
│   ├── Components.swift          Usage bars, app icons, verdict badges, the trial/licence badge
│   ├── RamClean.entitlements     Apple Events (quitting apps under the hardened runtime)
│   ├── Assets.xcassets/          App icon (generated by scripts/make-icon.swift)
│   ├── NotificationArt/          Pictures attached to notifications (scripts/make-notification-art.swift)
│   └── Info.plist                Generated by xcodegen from project.yml
├── RamCleanCore/                 All the logic, as a Swift package (swift test)
│   ├── Package.swift
│   ├── Sources/RamCleanCore/
│   │   ├── ProcessSampler.swift  Per-process memory, CPU and terminal info (libproc)
│   │   ├── SystemSampler.swift   Memory, pressure, swap, CPU, disk
│   │   ├── ActiveWork.swift      Busy check: builds, Claude Code, audio, sleep assertions
│   │   ├── AudioActivity.swift   Which processes are playing audio
│   │   ├── AppGrouper.swift      Helpers → apps; terminal work → hosting app
│   │   ├── Preferences.swift     Every setting and its default
│   │   ├── HabitStore.swift      Habit log and activity diary
│   │   ├── Features.swift        Model features and the rule-of-thumb score
│   │   ├── Protection.swift      Never-suggest rules
│   │   ├── DeadweightModel.swift Create ML classifier, training answers, blending
│   │   ├── Assessor.swift        Verdicts, notification policy, CPU averages
│   │   ├── QuitReason.swift      The short reason on each quit suggestion
│   │   ├── DiskScanner.swift     What to clear or move: caches, stale project builds, unused apps, old downloads, large files, Trash
│   │   ├── KillLedger.swift      Follows apps RamClean quit for 30 minutes to learn whether you wanted them back
│   │   ├── Forecast.swift        Disk-full forecast and apps whose memory has swollen
│   │   ├── Alerts.swift          Threshold alerts (memory, CPU, disk) and the recommendations they carry
│   │   └── Licensing/
│   │       ├── ProductConfig.swift   Price, trial, grace, checkout, appcast, store IDs: the one place to change them
│   │       ├── Licensing.swift       Trial clock, licence record, the state shown in the UI
│   │       ├── LemonSqueezy.swift    License API client (activate, validate, deactivate)
│   │       └── SecureStore.swift     Keychain, UserDefaults and in-memory stores
│   └── Tests/RamCleanCoreTests/
│       ├── RamCleanCoreTests.swift
│       ├── LicensingTests.swift  Licensing against a fake HTTP client
│       ├── SampleBenchmark.swift Opt-in timing of a live check (RAMCLEAN_BENCH=1)
│       └── ScanBenchmark.swift   Opt-in timing of a real disk scan (RAMCLEAN_BENCH=1)
├── site/                         The product website (static HTML, light and dark, phone-friendly)
│   ├── index.html                Landing page: screenshots, price, Buy and trial download
│   ├── privacy.html              What leaves the Mac (licence and update checks only)
│   ├── terms.html, refund.html   Templates for legal review
│   ├── style.css
│   └── images/                   Screenshots and icon, copied from docs/images
└── docs/
    ├── INSTRUCTIONS.md           Setup, run, use, data files
    ├── SYSTEM-DESIGN.md          Architecture, flows, decisions, limits
    ├── GO-LIVE.md                What the owner does before selling: Apple, Lemon Squeezy, Sparkle keys, hosting
    ├── FILE-STRUCTURE.md         This file
    └── images/                   Screenshots and the 1024 px icon used by the README
```

Not in the repo: `build/` (build output, including `build/release/` from release.sh), `site/download/` and `site/updates/` (DMGs and the appcast, uploaded with the site), and `RamClean.xcodeproj` (regenerate with `xcodegen generate`). Your data lives outside the repo, in `~/Library/Application Support/RamClean/`.
